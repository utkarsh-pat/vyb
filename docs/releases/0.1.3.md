Release date: 2026-07-29

- Product/workspace version: `0.1.3`

Firebase-generated Data Connect Admin SDK packages retain their generator-owned
versions; they are generated contracts rather than independently released Vyb

The debug APK is for internal device QA. A Play-distributed release must use
the configured release signing credentials and a release build.

The QA/debug artifact defaults to `https://api.vybnet.app/` so it works on
physical devices. Emulator-only local backend development must opt in with
`-PvybApiBaseUrl=http://10.0.2.2:4000/`.

## Backend deployment scope

The Cloud Run image installs only production dependencies for
`@vyb/backend` and its required `@vyb/config` workspace dependency. Mobile,
web, documentation, tests, local artifacts, Firebase cache, local backups, and
backend backup files are excluded from the build/deployment context.
Only the six generated Data Connect Admin SDK directories imported by backend
runtime modules are included; unrelated generated connectors are excluded.
The verified Cloud Build upload allowlist contains 81 files totaling about
1.19 MiB, with no local `node_modules`, APKs, screenshots, tests, migration
scripts, Vercel metadata, or backup data.

Cloud Run is configured with zero minimum instances, a ten-instance maximum,
and concurrency of 80. This prevents idle instance cost and adds an explicit
autoscaling cost ceiling while retaining room for burst traffic.
